# What the MIT licence covers

Rueca's **code** is open source under the [MIT licence](LICENSE): the kit (`src/kit/`), the agent
skill (`skills/`), the Claude Code plugin, the component registry, the scripts, the tests and the
example tools (`src/shells/`, including their demo artwork). Use it, change it, ship it.

Rueca's **brand** is not. The MIT licence does not cover:

- the name **Rueca** used as the name of a product, project or service;
- the Rueca logo, mark and wordmark, in any file or form (including `src/landing/logo.generated.ts`);
- everything in [`brand/`](brand/): the brand board, logo studies, palettes, type work and research;
- the design, artwork and copy of the rueca.dev site (`src/landing/`), and its share image and icon
  (`public/og-*.jpg`, `public/favicon.svg`).

These are © 2026 Rafael Cespedes, all rights reserved. They are in this repository so the site can
be built and so you can see how it was made, not for reuse.

The site's display font, Sorts Mill Goudy, keeps its own licence (SIL Open Font License,
[`src/landing/fonts/OFL-sorts-mill-goudy.txt`](src/landing/fonts/OFL-sorts-mill-goudy.txt)).

## Using the name and logo

- **Fine:** saying your tool is "built with Rueca" or "uses the Rueca kit", linking to rueca.dev,
  and writing about Rueca.
- **Not fine without asking:** naming a fork, product or package "Rueca" (or something easily
  mistaken for it), using the logo or brand artwork, or presenting your work as official Rueca.

If you fork the project to publish your own version, give it a different name and visual identity.
For anything else, ask: [rafaelcespedes.com](https://rafaelcespedes.com).
