# Security

## Reporting a vulnerability

Please don't open a public issue. Report it privately through GitHub instead:
[Report a vulnerability](https://github.com/rueca/rueca/security/advisories/new)
(the repository's Security tab → Report a vulnerability).

Include what you found, where (the kit, the agent skill, the plugin or the site), and
the steps to reproduce it. I'll reply within 7 days, work on the fix in a private
branch, and credit you in the advisory unless you'd rather stay anonymous.

## What's covered

- The kit components served from the registry at `rueca.dev/r/`
- The agent skill and the Claude Code plugin in this repository
- The site at rueca.dev

Fixes land in the latest release only. Rueca is pre-1.0, so update to the newest
version before reporting.
