# Moods

The wheel's range (research/28, device 1: the wheel is the character, with no face and no figure). It's the exact Pulido mark in five states, each made from the race's own moves: colour folds sweeping round a wheel, and the band filling like thread. Each motion is named with a spinning word. **The names are proposals**, still to be run through copywriting before RUECA.md §7 adopts them.

| Mood | Name | What moves |
|---|---|---|
| Working | *Hilar*, to spin | Fans race round the wheel without stopping. The whorl turns twice as fast because it's half the size. |
| Idle | *Cardar*, to card | One slow Malva fan, then the ink wipes it clean. |
| Snag | *Torcer*, to twist | An Achiote fold catches, snaps back past its start and settles. The band kinks where it caught. |
| Loading | *Devanar*, to wind | Thread winds along the band, then clears. |
| Done | *Hilar*, the race | The approved E2 race, once, then the mark rests and clears for the next loop. |

Only the wheel turns (RUECA.md §7, rule 6). All five share one loop (4.8 s), so the board stays in step.

Open it with the `brand-board` dev server at `/brand/moods/`. Show all five or one large, on Lana or Nogal, and export a PNG or one loop as video.
