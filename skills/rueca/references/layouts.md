# Layouts and pro-tool conventions

## Pick the archetype from the artifact

| Artifact | Archetype | Kit layout |
|---|---|---|
| Motion study, component, artboard-sized thing | Artboard + inspector + timeline | `islands` |
| Shader, 3D scene, photo effect, generative full-bleed | Full-bleed stage under floating panels | `overlay` |
| Dense editor: UI design, flows, node graph, journey map | Flush panels (Figma UI3) | `docked` |
| Keyframed animation, state machines | Mini After Effects: layers L, canvas, inspector R, timeline B | `docked` or `islands` |
| Asset generator, social/ad sizes | Grid of sizes + data table + export queue | `docked` |
| An existing prototype | Iframe artboards × breakpoints + inspector | `islands` |
| Client demo | Full-bleed art + published controls in a sheet; works on a phone | present view |

## Canvas

- Space-drag pan, ⌘wheel / pinch zoom at the cursor, `Shift+0` 100%, `Shift+1` fit,
  `Shift+2` selection. Zoom pill bottom-right.
- Zoom via `transform: scale()` on a wrapper whose own box is `size × zoom`, so layout
  reflows. Artboard: deep shadow, 1px ~5% ring, label above top-left.
- No dot grid on a motion artboard (it competes); a faint grid is fine on infinite
  canvases.
- Bottom-centre floating tool dock (36px, `h-dock`; buttons `size-dock-button`). A selection-aware context bar (Affinity)
  with 3–6 actions.
- `⌘\` hides all chrome (present mode).

## Inspector

- 24px rows, 22px controls, 11px tabular values (the default density). The label column fits the
  longest visible label in the panel, from 72px up to 42% of the row. Labels visible
  (keep `aria-label` if hidden).
- Sections 26px high, collapsible, collapse state persisted, hover-revealed reset;
  Alt-click solo-opens.
- Row context menu: Reset · Copy / paste value · Add key · Copy as CSS. Double-click
  label = reset. A dot or full contrast marks changed values.
- Fills, effects and materials are **stacks**: `+` in the header; each row swatch,
  value, opacity, blend, eye, remove; drag to reorder.
- Rive-style **inputs** (Trigger / Boolean / Number) to expose prototype state.

### What shows at rest

Every control gets one home on screen, plus ⌘K. The author picks it in the schema; never reorder by usage.

| Home | What goes there | How |
|---|---|---|
| In view | What the presets vary and what gets tuned every session. About 8–12 rows; the resting inspector fits a 13-inch laptop without scrolling. | Open sections, the core rows first |
| "N more" | The tail of a section: same topic, rarely touched | `more: true` on the param |
| Off until wanted | An optional feature (vignette, grain, delay, shadows) | `folder(…, { toggle: 'key' })`: a switch in the header |
| Settings | View and document preferences: grid, snap, nudge, fps, units, export scale | `folder(…, { place: 'settings' })` + `<SettingsMenu>` in the toolbar |
| ⌘K only | Rare commands, and controls kept for the few who need them | A palette command |

- **Rank by evidence.** A param the presets change belongs in view. A param no preset touches, sitting at its
  default, is a "more" candidate. Send to agent notes (`.rueca/notes/`) show what people actually tune.
- **Sections in order of use.** The section people open first comes first: dither puts Effect before Adjust.
- **Child under parent.** A row that only matters when another is on gets `when`, so it hides until then.
- **Never nest values people glance at, two-option choices or colour.** Figma moved all three behind icons in
  UI3 and moved them back after complaints.
- **Two levels at most:** section → popover. Never a popover inside "more" inside a collapsed section.
- **Hidden state stays visible.** A changed value under "more" stays in view; a collapsed section with a changed
  value shows the dot; a popover's trigger shows its value, never an icon alone.
- Affinity **Studios**: mode presets that swap the panel set (Design / Animate / Tune).

## Timeline

- Seconds by default, frames optional; dual readout `1.250s / f75 @60`.
- Labelled ruler (ticks 250ms, labels 500ms), rounded lane bars, playhead hairline
  with a handle in `rec`. Click / drag the ruler to scrub; Shift snaps to keys.
- Diamonds for keys; the segment between keys shows its easing; dashed = hold. Click a
  segment → easing popover.
- Loop region (Shift-drag ruler); Loop / Once / Ping-pong.
- **Collapsible** — it is the first thing in the way when the artboard is tall.
- Lanes are **derived from the render maths**, never a hand-kept list.

## Layers

24px rows (`--row`), 12px indent, type icon, thumbnail on checker, eye / lock on hover (kept
visible when active), 2px accent insertion line on drag, effects as child rows,
Alt-click eye = solo, Alt-chevron = expand all.

## Node graphs

Ports 8px coloured by type, header category stripe, Tab / double-click = add-node
search, selection fills the inspector.

## Photo / colour

`\` before/after (hold to peek), `Y` split view, histogram with clipping triangles,
Lift / Gamma / Gain wheels with luminance ring and reset, hover a preset = preview.

## Borrow from each reference tool

- **Spline:** empty selection → scene settings; materials and effects as stacks;
  dot-to-bind; `⌘\` hides UI.
- **Paper:** OKLCH first-class; slider detents at default and round values; on-canvas
  spacing handles.
- **Figma:** the default mental model for rows, hover affordances and the Motion
  timeline grammar. Exceed it on colour.
- **Framer:** property-control schema as the inspector API; Duration + Bounce springs.
- **Affinity:** expression validity tint (red / green), `w`/`h` references in fields,
  selection-aware context bar, Studios.
- **Rive:** 3-state key button; Trigger / Boolean / Number inputs; pt / % toggle in
  fields.
